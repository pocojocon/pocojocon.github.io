Política de privacidad

Esta política describe el sitio de presentación y el componente de respaldo de PATRIMONIO RADAR, una aplicación personal mantenida por el titular de la cuenta de GitHub pocojocon.

1. Alcance y finalidad

La aplicación organiza información pública sobre empresas y conserva un historial privado de investigación. Google Drive se utiliza para guardar y recuperar respaldos cifrados del propietario, comprobar su integridad y facilitar la recuperación ante fallos.

2. Datos de Google a los que se accede

El componente de respaldo solicita únicamente https://www.googleapis.com/auth/drive.file. Accede al contenido y los metadatos de los archivos utilizados por la aplicación, incluidos identificadores, nombres, tamaños, ubicación, permisos disponibles y dirección de correo del propietario cuando Google la facilita para comprobar la propiedad. Consulta la cuota de almacenamiento para evitar superar el espacio disponible.

Los paquetes pueden contener bases de datos, configuraciones sin secretos, fuentes públicas e informes y notas privadas del propietario, siempre cifrados antes de su subida. El permiso no se utiliza para explorar todo Drive, leer Gmail, contactos o calendarios.

La publicación opcional de informes en una hoja privada de Google Sheets utiliza una identidad de servicio independiente; el token OAuth de los respaldos no se utiliza para ampliar el acceso a Sheets.

3. Uso y almacenamiento

Los datos se utilizan exclusivamente para almacenar, verificar y recuperar el estado del proyecto. Se procesan en el equipo del propietario o, cuando se utiliza la ejecución remota, en GitHub Actions dentro del repositorio privado del proyecto.

Drive almacena los paquetes cifrados. Un registro privado de GitHub conserva los metadatos mínimos para identificar los paquetes confirmados y comprobar sus hashes. Las credenciales OAuth se guardan en archivos locales con permisos restringidos o en GitHub Secrets para las ejecuciones remotas. No se incluyen en las copias de seguridad, el código público ni los informes públicos. La clave de cifrado no se incluye con los paquetes.

4. Proveedores y acceso

Google presta los servicios de autorización y almacenamiento de Drive. GitHub aloja este sitio y puede prestar los servicios de ejecución y registro privado descritos. El acceso operativo se limita al propietario y a las identidades técnicas autorizadas por él para ejecutar estas funciones.

No vendemos los datos ni los utilizamos para publicidad, perfiles comerciales, entrenamiento de modelos de inteligencia artificial o finalidades ajenas al respaldo y funcionamiento descritos. No se publican los respaldos, las notas privadas ni las credenciales en este sitio.

El uso de información recibida de las API de Google se ajustará a la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado cuando resulten aplicables.

5. Conservación y eliminación

Las generaciones de respaldo se conservan mientras el propietario necesite mantener el historial de recuperación; no existe un borrado automático por antigüedad. Los archivos incompletos pueden conservarse para diagnóstico y recuperación. El propietario puede eliminar los archivos de Drive y las copias locales, así como las credenciales y los registros privados de GitHub, utilizando los controles de cada servicio.

Retirar la autorización no elimina las copias existentes. Eliminar un respaldo puede impedir recuperar las generaciones que dependan de él. La eliminación y retención residual de los proveedores se rigen también por sus propias políticas.

6. Revocación de acceso

El propietario puede retirar el acceso desde las conexiones de terceros de su cuenta de Google, seleccionando PATRIMONIO RADAR. También puede detener las ejecuciones y retirar los Secrets de GitHub. Tras la revocación, la aplicación no podrá renovar el acceso y se detendrá al fallar la autorización.

7. Visitas a este sitio

Estas páginas no incluyen formularios, analítica, publicidad, scripts ni cookies propias de la aplicación. GitHub Pages registra la dirección IP de las visitas por motivos de seguridad, según su política de privacidad. Los enlaces externos se rigen por las políticas de sus respectivos servicios.

8. Contacto y cambios

Para preguntas de privacidad o solicitudes relativas al proyecto, contacta con su responsable mediante el canal público de contacto. Indica únicamente que necesitas tratar una consulta privada; no adjuntes datos personales, tokens, claves ni respaldos.

Los cambios se publicarán en esta página con su fecha de actualización. Si cambia el acceso a datos de Google o su finalidad, se actualizará esta política y se solicitará el consentimiento correspondiente antes de ampliar el tratamiento.
